# SheCan-Form
A simple responsive contact form for She Can Foundation built using HTML, CSS, and JavaScript. Includes form validation, interactive UI, and localStorage integration to simulate data handling without a backend.
## Features
- Form validation (name, email, message)
- Responsive design
- Interactive UI with button states
- Data stored using localStorage
- Clean and beginner-friendly code

## Tech Stack
- HTML
- CSS
- JavaScript
